The X Subscription 上线：Grok + Cursor + X 并一张账单，谁该切、谁别动

2026-10-12 起，新客默认走 The X Subscription——一张单覆盖 Grok、Grok Bot、Cursor 和 X Premium；老订户可以不切，但一切就永久合并，且 Cursor 里 Claude / GPT 等第三方模型从第一刀按 API 价计费。

适用：已经在付 SuperGrok / Cursor / X Premium，或准备新开 Grok + 写代码的人。只刷 X、不用 Grok 也不写代码的，当新闻看就行。

新五档（别和旧 SuperGrok 梯子混）

档 月付 相对 Plus 一句话
Free $0 Limited 试用
Plus $8 Base 轻度 AI + X 蓝标；无 Grok Bot
Premium $30 4× 官方口径约等于旧 SuperGrok + Cursor Pro + X Premium+（曾约 $90）
Super $100 15× 聊天 / Imagine / Cursor / Bot 一起重度用
Ultra $200 50× 新客顶档；不是旧 Heavy $300 改名

旧计划不会被强制砍。不切就继续现价现功能；新客才只能买新梯子。以后若整体迁移会提前通知，目前没截止日期。

额度怎么扣（坑在这）

  • 共享周池：Grok 网页/App、X 上的 Grok、Cursor 里的 Grok 模型共用；一周重置。
  • 第三方不进池：Cursor 里 Claude / GPT 从第一刀 API 价 + 预付 top-up。老 Cursor 若有第三方 included 额度，一切就没了——论坛吵得最凶的就是这条。
  • Bot 吃同一池，不是另一桶随便灌。

已经三家都在付、且 Cursor 主力是 Grok 模型的人，Premium $30 宣传账最香；Cursor 几乎全是 Claude / GPT 的，并完可能从订阅内额度变成按 token 开闸，先看模型占比再动手。

该不该切

现状 建议
新客 直接 x.ai/pricing
同时付 SuperGrok + Cursor（+ X），Cursor 主力 Grok 评估 Premium $30 / Super $100
只付 SuperGrok，几乎不用 Cursor 先不切（合并永久）
Cursor 重度吃 Claude / GPT 先别切，或先估一周 API 成本
只要 X 蓝标 Plus $8 即可
旧 Heavy $300 犹豫续不续 先看 Super $100 / Ultra $200 是否够用

硬规则： 合并 = 永久，Support 撤不回。（点击可查看官方文档：如何将账户统一到 X 订阅下）

怎么切（三步）

  1. 入口：Cursor 走 cursor.com/unify；Grok 走 Settings → Billing 或 accounts.x.ai/unify；从 X 切不带 Cursor，有付费 Cursor 请从 Cursor 开切。
  2. 结账前核对：档位、将被取消的旧订阅、按比例退款说明。
  3. Apple 买的 Cursor：系统不能代取消/退款，必须自己去 iPhone/iPad 订阅里停，并找 Apple 退；切完查邮件（含垃圾箱）。Google Play 买的也要回订阅页确认没双扣。

合并后账单在 grok.com/dashboard。某一侧显示还能试用、另一侧已订阅时，别连开第二单，带着两个邮箱找 support@x.ai。

旧开通路径仍可参考：注册升级、Premium+ 绑 Grok、Grok Bot。新统一订阅以官网结账为准。短期不打算合并、只卡在 SuperGrok 支付，可走 cnmgrok.com（不等于代开 The X Subscription）。

我的建议

  1. 三家都在付 + Cursor 主力 Grok → 打开 unify，重点看 Premium $30。
  2. Cursor 重度 Claude/GPT → 先留旧计划。
  3. 只有 SuperGrok → 不必为新牌子点永久合并。
  4. 新客 → 直接新梯子；日常先 Premium，顶不住再 Super；几乎不依赖第三方、15× 也不够再谈 Ultra。
  5. 别做：没看模型占比就冲 Ultra；Apple Cursor 忘取消导致双扣；工作号和个人号随手并。

一句话： 三家都付且吃 Grok → 评估 Premium/Super；Cursor 吃 Claude/GPT → 先别切；只玩 Grok → 可不动；新客 → 从 Premium 起算。

FAQ

不切会被停吗？
官方说现计划继续；未来迁移会提前通知，目前没截止日期。

切完还能回旧计划吗？
不能。合并永久。

第三方还有套餐内额度吗？
新计划没有；未切换的老 Cursor 可继续原规则。

Premium $30 一定更便宜吗？
只有你本来就要三件套才划算；只要其中一两样，或 Cursor 全靠第三方，账要重算。
