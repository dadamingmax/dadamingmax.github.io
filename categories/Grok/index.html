Grok 4.5 发布：性能进第一梯队，价格却砍掉一半，马斯克说"Opus 级"

Jul 9 2026 Grok 10 minutes read (About 1470 words)

Grok 4.5 发布了,官方这次连”聊天机器人”这个标签都懒得贴——直接说这是为写代码、跑长任务、干知识工作准备的模型,还是跟 Cursor 一起练出来的。

这事儿本身就挺有意思。以前提起 Grok,大家第一反应是马斯克、是 X、是敢说敢怼,编程能力从来不是它的标签。这回不一样,讨论全在围着”能不能干活”转。

跟 Cursor 一起训练,是这次真正的关键

官方发布页写得挺直白:Grok 4.5 是跟 Cursor 联合发布的,训练数据里塞了万亿级别的 Cursor 真实使用数据——开发者怎么改代码、Agent 怎么调工具、怎么从错误里爬出来,这些都喂进去了。

这跟以前”刷榜”的打法不是一回事。SWE-Bench、HumanEval 这些榜单再高,也比不上真实 IDE 场景里几百万开发者天天产生的交互数据值钱。Hacker News 上有条评论说得挺准:这可能是 Cursor 手里最值钱的资产,比它的编辑器本身还值钱。

当然争议也在这——用户改代码的时候,有多少人真的清楚自己的操作被喂进了下一代模型?企业客户尤其在意这个,透明度和 opt-out 机制目前都还没讲清楚。

跑分:进了第一梯队,但不是天花板

具体数字上,Grok 4.5 在 Terminal-Bench 2.1 上跑到 83.3%,跟 GPT-5.5(83.4%)、Fable 5(84.3%)基本贴身;SWE-Bench Pro 上是 64.7%,比 Opus 4.8 低一截,但甩开了 GPT-5.5。Artificial Analysis 给它的综合排名是全网第 4,输出速度 87.6 token/秒,上下文 50 万 token。

翻译成人话就是:不是最强,但已经不是陪跑的了。X 上不少人的反应是”没想到 Grok 这次真到了 Claude、GPT 这个档位”。

真正的杀招是价格

输入 2 美元/百万 token,输出 6 美元/百万 token——这个价格摆出来才是这次真正的冲击。同样水平的模型,Opus 4.8 报价是 5/25 美元,GPT-5.5 也不便宜。如果能力真能打平,价格却是零头,企业客户没理由不认真算这笔账。

马斯克自己在 X 上补了一刀:现在这版还没用上他们给 GB300 定制的推理软件,速度以后可能还能翻倍,上下文窗口也快要冲到 100 万 token了。这话听听就好,但方向是清楚的——xAI 这次是拿”模型+工具+算力+价格”打组合拳,不是单靠一个跑分数字。

实测反馈:真项目里能干活

开发者反馈里比较有代表性的是两类:一是有人拿它去优化 oxlint,一次就挑出十几个性能问题;二是有人把自己放了好几年、依赖全乱套的老项目丢给它,居然被重新跑起来了。这种”读懂一个陌生烂摊子”的能力,恰恰是真实工程里最难的部分,比写个 demo 有说服力得多。

但也有人提到,长对话跑到后半段,Grok 4.5 有点”变懒”的迹象——响应变敷衍,这个还需要更多人验证。

信任问题绕不开

Hacker News 那条讨论下面几百条评论,吵得最凶的不是跑分,是信任。Grok 过去在政治立场、内容尺度上的争议不少,不少人说这让他们很难把它放进正经的商业场景里用。也有反方观点:所有模型厂商都会通过系统提示词和后训练去塑造输出风格,区别只是做得明不明显。

这话说得也在理——但对企业用户来说,“透明”和”可控”从来都比”聪明”更重要。

国内 Grok 注册教程：如何开通 Grok，并升级 SuperGrok 订阅？（2026 年 7 月最新版）

Jul 6 2026 Grok 24 minutes read (About 3532 words)

最近很多国内 AI 用户开始关注 Grok。

一方面，是因为 Claude、ChatGPT 这类工具在账号风控、地区限制、内容限制上让不少人觉得麻烦；

另一方面，Grok 在创意写作、网文构思、漫画分镜、图片生成、视频生成、DeepSearch 搜索等场景里，确实有自己的特点。

如果你只是偶尔体验，免费版 Grok 就能用。 但如果你想长期用 Grok 写文章、做图、生成视频、查资料，或者体验更完整的 Grok 功能，那就需要了解 SuperGrok。

这篇直接讲清楚：

  • 国内怎么注册 Grok？
  • Grok 官网和 X 上的 Grok 有什么区别？
  • 免费 Grok 和 SuperGrok 有什么区别？
  • 国内用户怎么升级 SuperGrok？
  • 升级后不显示 SuperGrok 怎么办？

建议收藏，后面注册和升级时可以直接对照操作。

一、国内可以注册 Grok 吗？

可以。

国内用户注册 Grok，主要需要准备两个东西：

  1. 一个邮箱
  2. 一个能正常访问 Grok 的网络环境

邮箱没有太多限制，常见的 QQ 邮箱、163 邮箱、Outlook、Gmail、自定义域名邮箱，一般都可以用来注册。

Grok 官网入口：

打开官网后，按照页面提示注册账号即可。整体流程和注册其他 AI 工具差不多：填写邮箱、接收验证码、完成登录，然后就可以进入 Grok 使用页面。

二、Grok 官网和 X 上的 Grok 有什么区别？

很多人会把 Grok 官网和 X 上的 Grok 混在一起。

简单说：

grok.com 是 Grok 的独立官网。

x.com 是 X，也就是原 Twitter 平台里的 Grok 入口。

两边都能用 Grok，但账号体系和订阅体系并不完全一样。

如果你平时主要刷 X，经常看海外 AI 动态、发帖、看推文，那么可以考虑在 X 里使用 Grok。

但如果你的目标很明确，就是想专门使用 Grok 聊天、写作、生成图片、生成视频、做 DeepSearch 搜索，那更建议直接使用 grok.com 官网。

原因也很简单：

X 会员是围绕 X 平台设计的，Grok 只是其中一部分权益。 SuperGrok 是围绕 Grok 本身设计的，更适合专门使用 Grok 的用户。

所以选择方式可以直接记住一句话：

经常用 X，就考虑 X 会员。 专门用 Grok，就直接看 SuperGrok。 只是想体验，先用免费版。

三、免费 Grok 和 SuperGrok 有什么区别？

免费版 Grok 适合轻度体验。

你可以用它问问题、写简单内容、试试模型风格，也可以体验部分基础功能。但如果你使用频率比较高，很快就会遇到限制。

免费版常见限制包括：

  • 消息次数有限
  • 高峰期容易变慢
  • 图片和视频生成次数较少
  • 上下文长度较短
  • 部分高级功能不可用
  • 新功能不一定第一时间开放

SuperGrok 则更适合高频用户。

升级 SuperGrok 后，通常可以获得更高的使用额度、更稳定的访问体验、更长的上下文、更完整的图片和视频生成能力，以及部分新功能的优先体验资格。

如果你经常使用下面这些功能，SuperGrok 会更有价值：

写公众号文章/ 写知乎回答/ 写短视频脚本/ 写网文大纲/ 做漫画分镜/ 生成图片素材/ 生成视频素材/ 使用 DeepSearch 查资料/ 进行长对话/ 体验语音和 Companion 功能

不过也要说清楚，Grok 不一定适合所有场景。

四、国内用户为什么升级 SuperGrok 会失败？

国内用户注册 Grok 通常不难，真正麻烦的是支付。

SuperGrok 官方订阅一般需要海外支付方式，比如 Visa、MasterCard 等国际银行卡。很多国内用户没有这类卡，即使有虚拟卡，也可能遇到支付失败、风控拒付、账单地址不匹配等问题。

常见失败原因包括：

  • 银行卡不支持海外订阅
  • 虚拟卡被拒付
  • 账单地址不匹配
  • 支付环境异常
  • 账号触发风控
  • 浏览器缓存导致页面异常

所以国内用户升级 SuperGrok，通常有两种方式：

第一种：自己用海外卡在 Grok 官网订阅。

第二种：通过国内 SuperGrok 升级入口，用账号 ID 完成充值。

如果你有稳定可用的海外卡，可以直接走官方订阅。

如果你没有海外卡，或者多次支付失败，可以考虑账号 ID 直充方式。重点是：尽量选择不需要账号密码的方式。

不要随便把 Grok 账号、邮箱密码、X 密码交给别人。

五、国内如何升级 SuperGrok？账号 ID 直充教程

如果你使用的是账号 ID 充值，一般流程很简单。

第一步：先注册并登录 Grok

先打开 Grok 官网：

grok.com

完成注册并登录账号。

确认你能正常进入 Grok 聊天页面后，再进行下一步。

第二步：找到自己的 Grok 用户 ID

账号 ID 是升级 SuperGrok 时最关键的信息。

现在官方已经没办法通过页面直接查看你的 Grok ID 了。

在有登录的 grok 的账户页面端，访问 grok.com/api/auth/session 账户页面，找到您的账户 ID（你的userid就是你的grok ID）。

第三步：进入 SuperGrok 升级入口

如果你没有海外卡，可以使用国内 SuperGrok 升级入口：cnmgrok.com

选择 SuperGrok 对应套餐，按照页面提示填写信息。

填写购买的充值码和你的 grok id 即可完成充值。

这里再次提醒： 账号 ID 直充一般不需要账号密码。 能不提供密码，就不要提供密码。

第四步：等待 SuperGrok 到账

提交成功后，一般需要等待几分钟。

到账后，重新打开 Grok 页面，如果升级成功，页面一般会显示 SuperGrok 相关状态。

如果页面没有立刻变化，不一定代表失败，可能只是缓存或延迟。

可以尝试下面几种方法：

  • 刷新页面
  • 退出 Grok 后重新登录
  • 换一个浏览器打开
  • 清理浏览器缓存
  • 等待几分钟后再查看
  • 进入账号订阅页面确认状态

六、升级 SuperGrok 后不显示怎么办？

很多人升级后遇到的第一个问题就是：钱付了，为什么页面还是普通 Grok？

这种情况通常有几种原因。

1. 浏览器缓存没刷新

这是最常见的情况。

解决方法：

退出账号 关闭浏览器 重新打开 grok.com 再次登录查看

2. 到账有延迟

有时候系统不是秒到账，可能需要等几分钟。

解决方法：

不要重复提交订单 等待几分钟后刷新页面 进入账号设置查看订阅状态

3. Grok 用户 ID 填错

如果 ID 填错，可能会导致无法正常充值到你的账号。

解决方法：

重新进入账号页面 复制完整 Grok ID 和充值填写的 ID 对比 确认是否漏字符或复制错

4. 登录了另一个账号

有些人同时有 X 账号、Grok 官网账号，甚至多个邮箱账号，容易登录错。

解决方法：

确认当前登录的邮箱 确认当前账号 ID 确认充值时填写的是同一个账号

七、SuperGrok 适合哪些人开？

SuperGrok 不是人人都必须开。

如果你只是偶尔问几个问题，免费版就够了。

如果你每天都要高频使用 Grok，那 SuperGrok 会更合适。

比较适合升级的人群包括：

内容创作者/ 公众号作者/ 知乎运营/ 短视频编导/ 网文作者/ 漫画脚本创作者/ AI 绘图用户/ AI 视频用户/ 海外信息搜索用户/ DeepSearch 重度用户/ 喜欢语音聊天和 Companion 的用户

尤其是做内容的人，Grok 的优势很明显：它更适合发散思路、扩写脑洞、整理热点、生成脚本和做多模态素材。

八、Grok 和 SuperGrok 常见问题

1. 国内注册 Grok 需要手机号吗？

一般情况下，邮箱注册即可。具体是否需要额外验证，要以页面实际提示为准。

2. QQ 邮箱能注册 Grok 吗？

通常可以。QQ 邮箱、163 邮箱、Outlook、Gmail 等常见邮箱都可以尝试。

3. SuperGrok 可以用支付宝或微信支付吗？

官方订阅一般不直接支持国内常用支付方式。没有海外卡的用户，可以考虑国内升级入口（cnmgrok.com）。

4. 升级 SuperGrok 需要提供账号密码吗？

不建议提供账号密码。更推荐使用 Grok 用户 ID 直充方式。

5. X Premium+ 和 SuperGrok 是一回事吗？

不是完全一回事。

X Premium+ 是 X 平台会员，Grok 只是其中一部分权益。 SuperGrok 是 Grok 官网的独立订阅，更适合专门使用 Grok 的用户。

6. SuperGrok 适合写代码吗？

适合

尤其是搭配 Grok Build 后，原型开发和快速迭代效率很高。虽然大型重构略逊于 Claude，但对大多数开发者来说已足够实用且性价比高。

7. SuperGrok 更适合什么？

更适合写作、创意、图片生成、视频生成、DeepSearch、长对话、语音聊天和陪伴类功能。

九、总结：国内用户怎么选择 Grok 和 SuperGrok？

如果你只是想体验 Grok，先用免费版。

如果你是 X 重度用户，可以考虑 X 的会员体系。

如果你主要就是为了使用 Grok 本身，建议直接使用 grok.com，并根据需求升级 SuperGrok。

国内用户升级 SuperGrok，最大问题通常不是注册，而是支付。如果没有海外卡，或者官方支付一直失败，可以考虑账号 ID 直充方式。

最后再总结一句：

Grok 适合创作、搜索和多模态生成。 SuperGrok 适合高频使用 Grok 的用户。 国内用户升级时，优先选择不需要账号密码的方式，更安全也更省事。

先说一句重要的话:原生 Windows 是早期 Beta

在动手之前,这一点必须摆在最前面,因为它会影响你的选择。

Hermes 现在可以在 Windows 10 / 11 上原生运行——不需要 WSL、不需要 Cygwin、不需要 Docker。但官方明确把原生 Windows 标记为 early beta:它能装能跑,也通过了 Windows 相关的检查,但没有像 Linux/macOS/WSL2 路径那样被大规模实测过。粗糙的地方主要集中在子进程处理、路径怪癖和非 ASCII 控制台输出上。

所以请按这个判断来选:

  • 个人尝鲜、轻量 CLI、本地试用 → 原生 Windows 完全够用,按本文走
  • 要长期挂 gateway、跑长任务、多平台消息接入做生产自动化 → 官方建议优先用 WSL2 或 Linux 服务器

本文走原生 Windows 路径;文末会给出何时该切到 WSL2 的明确信号。

你将得到什么

跟完这篇教程,你会在 Windows 上拥有一个本地运行的 Hermes Agent,它用你的 Grok 订阅做推理,能跨会话记事,并且可以挂一个定时任务在后台自动跑。整个过程大概 15 分钟。

需要先确认的前提:

  • Windows 10 或 Windows 11(64 位;32 位会缺失 bash,功能受限)

  • 不需要预装 Python、Node.js 或 Git——安装器会自带一套隔离环境

关于依赖:Hermes 采用”零依赖”安装哲学。安装器会自行provision uv、Python 3.11、Node.js、ripgrep、ffmpeg,以及一份便携式 Git Bash(PortableGit,解包到 %LOCALAPPDATA%\hermes,不需要管理员权限,也不会碰你系统里已有的 Git)。如果你已经装了 Git,它会检测到并直接用。

第五步:让它在后台自动干活(Windows 上的关键差异)

Windows 关键差异: Linux 靠 cron / systemd;原生 Windows 上 gateway 跑成后台 PowerShell 进程,定时调度走 Windows 计划任务(Scheduled Task)。别处教程写 crontab 的地方,这里对应计划任务——照搬 Linux 教程最容易卡在这。 具体配置见官方文档:Windows (Native) Guide 的 “gateway as a Scheduled Task” 节,及 “Automate Anything with Cron” / “Daily Briefing Bot” 教程。三条纪律:

  1. 先在 hermes 交互模式手动跑通,确认输出符合预期
  2. 验证过的指令再固化成计划任务,别直接写没测过的调度
  3. 要实时信息优先用 Grok 原生能力(模型层内置 X / 网络搜索,不必拼多步外部工具)

Windows 常见问题速查表

教程类文章最有用的部分往往是出问题时怎么办。下面是针对 Windows 整理的高频情况:

  1. hermes 命令找不到 / 不是可识别的命令 几乎都是因为没开新窗口。PATH 改动不作用于已打开的终端。解决:关掉当前 PowerShell,开一个全新的窗口,再 Get-Command hermes 验证。
  2. 控制台中文/emoji 显示乱码 原生 Windows 的非 ASCII 控制台输出是已知粗糙点。可以在环境变量里设 HERMES_DISABLE_WINDOWS_UTF8=1 回退到旧的 cp1252 stdio 路径(主要用于排查),或改用 Windows Terminal 而非老式 cmd 窗口。
  3. “No xAI credentials found”(运行时报找不到凭证) 还没登录,或凭证文件被删了。解决:hermes model 选 xAI Grok OAuth provider,或直接 hermes auth add xai-oauth。
  4. 令牌过期但没自动重新登录 Hermes 会在每次会话前及遇到 401 时刷新令牌。若刷新令牌被吊销(你在 xAI 那边撤了授权,或账户轮换),它会给出明确的重新认证提示而非崩溃。解决:重跑 hermes auth add xai-oauth。
  5. “Authorization timed out”(授权超时) 回环监听有 180 秒有效窗口,没及时批准就超时。解决:重跑 hermes auth add xai-oauth 或 hermes model。
  6. “State mismatch (possible CSRF)” Hermes 发现授权服务器返回的 state 与发出的不一致。解决:重新登录;反复出现就检查是否有代理或重定向在篡改 OAuth 响应。
  7. PowerShell 报执行策略错误,脚本无法运行 当前会话临时放开:Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass,只作用于这个窗口。
  8. 想彻底登出 :hermes auth logout xai-oauth, 只想删某一条凭证池记录:先 hermes auth list xai-oauth 看清单,再 hermes auth remove xai-oauth <index|id|label>。
  9. 想干净卸载整个 Hermes 官方卸载路径会移除 schtasks 计划任务条目、启动文件夹快捷方式、hermes.cmd 垫片,删除 %LOCALAPPDATA%\hermes\hermes-agent\,并清理用户 PATH。注意:你的数据目录 %USERPROFILE%\.hermes 不在自动清理范围内,需要保留或手动删除自行决定。

什么时候该切到 WSL2

出现以下任一信号,转 WSL2:

  • 需要 dashboard 网页内嵌终端面板(原生 Windows 无 POSIX PTY,仅此功能被禁,其余原生可用)
  • 要做稳定的生产自动化(长任务、常驻 gateway、多平台消息)——官方明确建议优先 WSL2 / Linux
  • 频繁遇到子进程、信号、路径分隔符的怪问题

切换:PowerShell 里 wsl --install 装 Ubuntu,在 WSL 里跑 curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash。两套可共存——原生数据在 %LOCALAPPDATA%\hermes,WSL 在 ~/.hermes。

几条值得记住的实践纪律

  1. 实时数据 ≠ 准确数据。 Grok 可能把过时或讽刺内容当事实。高风险决策(金融、法律、危机)行动前交叉验证。
  2. 搜索成本会累积。 xAI 服务端搜索约 千次每天两三百次1/天,规模化要算进预算。
  3. 凭证当密码对待。 令牌在 %USERPROFILE%\.hermes\auth.json,能花你的订阅额度。别打包上传,别留在不可信机器,登出真的跑 hermes auth logout。
  4. 先手动跑通,再固化成计划任务。 摩擦降到只剩”点一下授权”后,决定成败的是你有没有先想清楚它会在哪出错。
