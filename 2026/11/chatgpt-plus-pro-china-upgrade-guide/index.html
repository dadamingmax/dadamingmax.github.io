四、手把手教程：6 步完成微信/支付宝自助充值

整个流程大约 3 分钟，按顺序操作即可：

1. 购买对应套餐卡密

访问 CNMGPT 官网 cnmgpt.com，选择需要开通的 ChatGPT Plus 或 Pro 套餐，使用微信或支付宝付款。支付完成后，妥善保存页面给出的充值卡密。

2. 登录待升级的 ChatGPT 账号

在当前浏览器中打开 ChatGPT 官网并登录你要充值的账号。如果你手里有多个账号，务必先核对头像里的邮箱地址，防止充错账号。

3. 粘贴卡密进行验证

打开 CNMGPT 自助升级页面：cnmgpt.com/upgrade

将刚才买到的充值卡密粘贴到输入框中，点击验证，通过后即可进入账号认证环节。

4. 获取并提交账号密钥

按照升级页面的指引获取你的 ChatGPT 账号密钥信息。

将密钥完整复制并粘贴到对应框内，系统会自动识别待充值的账号信息。

5. 核对信息并确认充值

仔细检查页面展示的账号邮箱和当前订阅状态。

确认无误后点击确定充值，耐心等待系统自动完成升级。注意：处理期间请勿反复提交卡密。

6. 刷新页面验收结果

提示充值成功后，回到 ChatGPT 官网刷新网页。点击个人头像，进入设置查看账户，看到当前套餐已变更为 Plus 或对应的 Pro 套餐（或者在设置里查看你的账单信息），即代表升级完成。

五、常见问题解答（FAQ）

1. 只有安卓手机或 Windows 电脑，没有苹果手机可以充值吗？

完全可以。充值全程在网页端完成，不需要 iPhone、iPad 或海外 Apple ID。而且会员权益绑定在 ChatGPT 账号上，开通后在网页端、Windows、Mac、iOS、Android 全平台通用。

2. 升级后会丢失以前的聊天记录和设置吗？

不会。原账号升级不会影响你原有的对话历史、项目（Projects）、记忆（Memory）以及个性化设置。

如果你是刚从 Claude 转过来的用户，也可以参考这篇

《Claude 数据导出并丝滑切换到 ChatGPT 教程》clawdo.com/2026/09/claude-export-to-gpt/

3. 已经是 Plus 会员，可以直接买卡密升级 Pro 吗？

这取决于账号当前的订阅状态和原有扣费渠道。已有生效订阅的用户，建议在下单前先咨询客服，确认能否直接覆盖升级，避免订阅冲突。

4. 到期后怎么续费？会自动扣款吗？

卡密充值到期后不会自动扣费，按当前账号状态重新购买卡密续费即可。如果账号此前绑定过其他渠道的自动续费，建议先检查并关闭原有订阅，防止重复扣费。

5. 充值后可以使用 Codex 吗？

可以。ChatGPT Plus 和 Pro 均包含对应的 Codex 使用权益，具体可用额度以 OpenAI 官方实时规则为准。

6. 提示充值成功了，但页面还是显示 Free 怎么办？

按以下顺序排查，切勿重复购买或重复提交卡密：

  1. 强制刷新 ChatGPT 网页；
  2. 核对当前登录的邮箱是否与充值邮箱一致；
  3. 退出账号后重新登录；
  4. 若仍未生效，直接联系平台客服核查订单状态。

7. ChatGPT 充值可以开具公司报销用的发票吗？

支持。有企业采购或报销需求的用户，请在付款前先联系 CNMGPT 人工客服，确认价格与开票流程。
